# Security

Do not report vulnerabilities by opening a public issue if it includes credentials, personal data, or an exploitable endpoint.

Use GitHub's private vulnerability reporting or a private security advisory for this repository when available. Include the affected area, impact, and a minimal reproduction. Do not include live API tokens or real user photos in a report.

If a credential was committed, revoke or rotate it with its provider even after removing it from the repository. Git history, clones, and cached copies may retain the old value.
